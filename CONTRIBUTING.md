# Contributing

Keep changes narrow, accessible, and evidence-based.

1. Create a feature branch.
2. Run `zed validate --require-lock`, `zed install --frozen --install-mode copy`, and `pnpm validate`.
3. Confirm compensation language does not promise an unpublished rate or guaranteed commission.
4. Confirm the human review remains blind to the AI assessment until submission.
5. Open a pull request and wait for required checks and review.

Do not submit real reports, customer information, reviewer identities, credentials, internal URLs, or private source.
