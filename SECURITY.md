# Security policy

## Report privately

Use GitHub's private vulnerability reporting for this repository. Do not open a public issue for a suspected vulnerability, exposed credential, reviewer-identity leak, sealed-assessment leak, or private report disclosure.

Do not include real customer reports, credentials, AI assessments, human reviewer identities, or production endpoints in a report. Use minimal synthetic evidence.

## Supported version

Only the site deployed from the current `main` branch is supported.

## Security boundaries

This repository is public and contains only static marketing content. It must not contain secrets, authentication logic, customer data, private package material, or production service configuration. Credentials pasted into chat, tickets, logs, or commits are considered compromised and must be revoked and rotated; deletion is not remediation.
